# Changelog - Magento 2 Free Shipping Progress Bar

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-11-09
### Added
- Dynamic Free Shipping Progress Bar for Luma (Knockout.js) and Hyvä Themes (Alpine.js + Tailwind CSS).
- Fixed hardcoded local URL bug and currency symbol resolution.
- Real-time cart subtotal tracking and instant progress calculation.
- Unit tests for threshold math and percentage calculations.
- PHP 8.1 - 8.4 support.
